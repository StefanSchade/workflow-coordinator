======================================================================
BINDING MAINTAINER DECISION (NOT OPEN FOR RE-LITIGATION)
======================================================================

Quoted verbatim from the design record's section 13:

  "A same-state Finding citation is an evidence-only operation and does NOT
  require finding_authority. finding_authority continues to gate only
  state-changing Finding transitions. P3 should make this distinction
  structural rather than infer it from a generic ExistingFindingDelta
  shape: citation and transition are separate result variants; citation
  must not carry transition-only fields such as proposed_state/
  successor_ref unless structurally required by its own semantics;
  transition variants remain subject to the existing disposition-authority
  checks; citation remains subject to ordinary structural/provenance
  validation, but not disposition authority."

Do not reopen whether citation should require finding_authority (it must
not), and do not reopen whether the split should be structural/parse-time
rather than reduce-time (it must be). These are settled. Your job is
implementation, not re-derivation.

IMPLEMENTATION OBJECTIVE
======================================================================

1. model.py -- split ExistingFindingDelta into two structural variants:

   - a citation shape (a FindingCitation-equivalent type) carrying
     finding_id and evidence_refs ONLY. It must not be possible to
     construct one with proposed_state, successor_ref, or
     new_material_evidence -- those fields must be absent from its type,
     not merely defaulted or ignored.
   - a transition shape (a FindingTransition-equivalent type) carrying
     finding_id, a typed disposition target distinguishing resolve /
     residual / supersede (carrying its own required successor reference)
     / reopen (carrying its own required new-material-evidence flag), and
     evidence_refs. successor_ref must live only on the supersede target's
     own shape, not as an optional field validated by a separate runtime
     predicate against proposed_state.
   - Leave NewFindingDelta (new-Finding authorship) exactly as it is today.
     This Commission touches only the EXISTING-Finding branch.
   - Choose exact type/field names via your own judgment and current
     repository naming conventions; the design record's FindingCitation/
     FindingTransition/ResolveFinding/ResidualFinding/SupersedeFinding/
     ReopenFinding names (section 4) are illustrative, not mandatory
     identifiers, but the SHAPE they describe is mandatory.

2. serialization.py -- parse the new wire shapes. Add a new
   result_contract_version 3 path for WORK_RESULT/REVIEW_VERDICT carrying
   the split shape. Do not alter how result_contract_version 1 or 2
   historical payloads parse; add a new branch, exactly as
   NEW_FINDING_DELTA_V2_KEYS was added only for result_version==2 without
   touching result_version==1 parsing (grep current source for this
   precedent before writing your own branch).

3. codex_adapter.py -- project the split shapes in the OpenAI strict
   anyOf, replacing today's single existing_finding schema node with two
   (one for citation, one for transition), for the new contract version.
   Keep contract versions 1/2's existing_finding schema node exactly as it
   is today.

4. reducer.py -- dispatch on the new types directly instead of computing a
   same_state comparison to classify a loose ExistingFindingDelta. The
   citation type must never reach _may_dispose/finding_authority -- by
   construction, because it carries no operation to check, not because a
   runtime branch happens to skip the check. The transition type keeps
   exactly today's _may_dispose/_finding_operation checks, atomicity, and
   cycle rejection, unchanged. This closes the already-accepted
   WI-WFC-GENERATIVE-ECHO-AUDIT-001 finding that a same-state citation of
   an already-superseded Finding should not have to restate successor_ref
   -- verify after implementation that this is true by construction (the
   citation type has no successor_ref field at all), not merely that a
   test happens to pass.

5. Preserve every existing reducer authority/atomicity/cycle/obligation
   check unless this Commission's own bounded split structurally requires
   touching one, per the RESIDUAL QUESTION section above.

Hop H1 (implement) is expected to cover all five items; correction Hops, if
needed, address independent_review/rereview Findings only.
