[[development]]
== Development and tests

From the repository root, use Python 3.10 or newer. A virtual environment keeps
the development tools separate from other projects:

[source,sh]
----
python3 -m venv .venv
.venv/bin/python -m pip install '.[dev]'
make check PYTHON=.venv/bin/python
----

The dev extra supplies build, pytest, pytest-cov and Ruff; the package depends on
PyYAML. `make check` runs lint, format-check and test. `make lint` checks Ruff's
configured correctness rules across the repository; `make format-check` checks
only the files listed in the Makefile. `make test` runs `python -m pytest -q`;
pytest already adds `-q` and discovers `tests/` through `pyproject.toml`.
`make coverage` and `make coverage-html` run tests with branch coverage, the
latter writing `build/htmlcov/`; `make build` builds distributions. Set `PYTHON`
to the chosen interpreter for any target. The root link:../../README.md[README]
retains the package quickstart and other maintainer commands.

Select checks for the behavior touched, then broaden as appropriate. Examples:

[source,sh]
----
.venv/bin/python -m pytest tests/unit/test_reducer.py
.venv/bin/python -m pytest tests/architecture/test_package_boundaries.py
.venv/bin/python -m pytest tests/unit/test_reducer.py -k route
----

Tests can use the configured `ftr` and `guardrail` markers. Integration tests
may depend on local facilities; read their skip conditions. In particular, the
Claude live smoke test is opt-in, requires an authenticated executable and
network access, and can incur a charge. A normal documentation change needs no
live provider Run.

=== Pytest scratch

`tests/conftest.py` leaves explicit `--basetemp` or `PYTEST_DEBUG_TEMPROOT` to
pytest. Otherwise it chooses the first nonempty `TMPDIR`, `TMP`, then `TEMP`;
the supplied directory must already exist, resolve outside `/tmp`, and, if
inside the checkout, be under `tmp/`. It creates a non-symlink `wfc-pytest`
child there. With none supplied, it uses the checkout's `tmp/pytest`, rejecting
symlinked scratch and a checkout under `/tmp`. Invalid or inaccessible scratch
fails configuration rather than falling back. Pytest controls numbered bases,
locks and retention; the selected base appears in the pytest header. An explicit
`--basetemp` has pytest's destructive reset semantics: choose it carefully.
This override affects pytest allocation only, not the environment or temporary
file choices of subprocesses and `tempfile`.
