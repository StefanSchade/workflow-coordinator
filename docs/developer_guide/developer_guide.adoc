Standing:: Informative guidance for developing and maintaining WFC; source and governing contracts retain their authority.

This guide covers development setup and checks, code navigation and debugging,
and maintenance judgment. For preparing, launching, observing, collecting
evidence from or recovering a Run, use the
link:{developer-docs}/operator_manual/operator_manual.adoc[Operator Manual].
The link:{developer-docs}/functional_model/workflow_program_use_cases.adoc[Functional Model]
explains purpose; the link:{developer-docs}/semantic_model/workflow_execution_semantics.adoc[Semantic Model]
explains meaning; the link:{developer-docs}/technical_model/workflow_program_architecture.adoc[Technical Model]
and link:{developer-docs}/architecture.md[architecture] explain mechanisms and boundaries.
