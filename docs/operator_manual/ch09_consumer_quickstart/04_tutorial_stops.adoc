[[tutorial-stops]]
== Tutorial 3 -- stops and the human decision

The third of
link:{operator-docs}/operator_manual/ch09_consumer_quickstart/00_overview.adoc#consumer-overview-tutorials[three
tutorials], using the same demo workspace Tutorials 1 and 2 built. Both
rehearsals here run without any model.

[[tutorial-stops-goal]]
=== Goal

Tutorials 1 and 2 both ended `completed`. This tutorial shows two ways a
Run does *not* reach that state, and how to read each one correctly: a
refusal before launch, and a stop that waits for a human.

[[tutorial-stops-task]]
=== The task

Scenario `t3-probe-refusal` reuses Tutorial 1's `t1-hello-page` task, but
its request's `evidence.argv` names `checks/not-there.sh` -- a script that
does not exist. Scenario `t3-scope-stop` uses its own task and request:

// kit: requests/t3-scope-stop.task.md
[source,markdown]
----
# Farewell page with a link

Create `docs/farewell.adoc` and link it from `docs/notes.adoc`.

## Acceptance

The task-check passes, `docs/farewell.adoc` exists, and it is linked from `docs/notes.adoc`.

## Withheld authority

No change outside `docs/farewell.adoc`.

## Default escalation

Stop and ask if the task cannot be completed inside the authorized scope.
----

// kit: requests/t3-scope-stop.request.yaml
[source,yaml]
----
schema_version: 1
commission_id: t3-scope-stop-001
work_item_id: WI-T3-SCOPE-STOP-001
authority_source: The workspace owner authorizes this bounded demo task.
program:
  id: simple
  revision: v1
task:
  title: Farewell page with a link
  body: Create `docs/farewell.adoc` and link it from `docs/notes.adoc`.
  acceptance: >-
    The task-check passes, `docs/farewell.adoc` exists, and it is linked
    from `docs/notes.adoc`.
  withheld_authority: No change outside `docs/farewell.adoc`.
  escalation_default: Stop and ask if the task cannot be completed inside the authorized scope.
scope:
  - docs/farewell.adoc
personas:
  worker: Implement exactly the authorized scope; stop and escalate rather than guess beyond it.
evidence:
  argv: [sh, checks/check.sh]
  timeout_seconds: 300
max_autonomous_hops: 3
durable_artifacts: {}
guidance:
  path: .wfc/governance/repository-policy.md
  source_commit: '{{GUIDANCE_COMMIT}}'
----

The task body itself asks for a change to `docs/notes.adoc` (a link), but
`scope` names only `docs/farewell.adoc` -- the mismatch is deliberate.

[[tutorial-stops-look-at]]
=== What to look at

* `wfc run`'s own exit code for `t3-probe-refusal` is `23`, and it printed
  no `CLASSIFICATION:` line -- a probe refusal happens before launch, so
  there is nothing yet to classify. A *later* `wfc status --repository
  greeter-run-t3-probe-refusal` call does print `CLASSIFICATION:
  not_launched`; that describes the checkout's own state at inspection
  time, not a result the refused Run itself reached.
* `git -C greeter-run-t3-probe-refusal log` shows only the kit's two seed
  commits -- proves nothing was committed by the refused Run.
* `t3-scope-stop`'s own exit code is `10`, `CLASSIFICATION: awaiting_human`,
  `stop reason mechanical_preemption:human_authority:scope`. Read the
  classification, not the exit code alone -- see
  link:{operator-docs}/operator_manual/ch03_running/02_launch_status.adoc#terminal-states[terminal
  states] for every classification this can print.
* `commits none` for the payload, but `wfc status` still reports an
  `ARCHIVE:` block -- the Commission commit exists (the Worker stopped
  before writing anything), and the stop itself was still archived.

[[tutorial-stops-human-decides]]
=== What the human decides

For `t3-scope-stop`, the correct decision is a new Commission whose scope
includes `docs/notes.adoc`, prepared in a fresh worktree (a stopped
checkout has spent its one lifecycle). This page states that one decision;
it invents no further procedure. See
link:{operator-docs}/operator_manual/ch06_recovery/01_outcomes.adoc[recovery
outcomes] for stops that leave work behind, and
link:{operator-docs}/operator_manual/ch03_running/02_launch_status.adoc#terminal-states[terminal
states] for every classification. For `t3-probe-refusal`, the decision is
simpler: fix the missing check command, then retry in a fresh worktree --
the refused checkout cannot be reused.

[[tutorial-stops-run]]
=== Run it live

[source,shell]
----
cd ~/wfc-demo
git -C greeter worktree add ../greeter-live-t3 -b live/t3 main
cd ../greeter-live-t3
wfc plan ../requests/t3-scope-stop.task.md --repository . --scope docs/farewell.adoc \
  --commission-id t3-scope-stop-001 --work-item-id WI-T3-SCOPE-STOP-001 \
  --authority-source "The workspace owner authorizes this bounded demo task." \
  --program simple@v1 \
  --persona worker="Implement exactly the authorized scope; stop and escalate rather than guess beyond it." \
  --evidence-argv sh --evidence-argv checks/check.sh --evidence-timeout 300 \
  --max-autonomous-hops 3 \
  --guidance-path .wfc/governance/repository-policy.md --guidance-commit <the kit's guidance commit>   # read-only preview
wfc run --repository . --request ../requests/t3-scope-stop.request.yaml \
  --executable claude \
  --execution-override worker.adapter=claude_cli \
  --execution-override worker.model=<your model> \
  --execution-override worker.reasoning=medium
----

Neither live command was executed for this page. A real Worker is expected
to stop on this mismatched scope, but may instead complete only the
in-scope part (creating `docs/farewell.adoc` without the link) and report
`completed`; either way the
link:{operator-docs}/operator_manual/ch02_commissioning/01_authority.adoc#mutation-scope[scope
enforcement] holds. Check it yourself afterward with `git -C
greeter-live-t3 diff --name-only main..HEAD` restricted to
`.wfc/governance/<commission-id>/` plus, at most, `docs/farewell.adoc` --
`docs/notes.adoc` should never appear.

[[tutorial-stops-verified]]
=== What was verified

On the installed `wfc` 0.1.0b1: `rehearse.py t3-probe-refusal` and
`rehearse.py t3-scope-stop` were executed against this exact working tree
and succeeded, matching their scenario's expected exit code and
classification; their output above is real. No live Run was performed for
this page.
