== Level-1 orchestration

This chapter is for a maintainer or operator running a second Claude Code
session *above* WFC, to decompose a larger goal into bounded Commissions,
launch and monitor each one, and keep every real decision with the human.
It assumes the rest of this manual, especially
link:{operator-docs}/operator_manual/ch01_orientation/_chapter.adoc#orientation[orientation],
link:{operator-docs}/operator_manual/ch02_commissioning/_chapter.adoc#commissioning[commissioning]
and
link:{operator-docs}/operator_manual/ch03_running/_chapter.adoc#running[running], and links
there for mechanics instead of repeating them. It does not describe an
integrated WFC capability; see <<level1-what-is-this>> below.
