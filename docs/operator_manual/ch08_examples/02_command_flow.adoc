[[command-flow]]
== Quick-reference command flow

Use this index from a WFC Development source checkout. `ATTEMPT` denotes
the Attempt identifier selected under the owning preparation procedure;
the command names below are navigation, not a second preparation recipe.

[cols="2,4",options="header"]
|===
|Command |Owning procedure and interpretation

|`python3 scripts/wfc_op.py prepare`
|link:{operator-docs}/operator_manual/ch03_running/01_preparation.adoc#harness-preparation[PREPARE]
owns input selection and the complete invocation. Its option reference covers
`--attempt`, `--development`, `--runtime`, `--evidence`, `--work-item`,
`--profile`, `--policy`, `--components`, `--task`, `--executable`,
`--timeout-seconds` and repeated `--role-binding` for worker/reviewer bindings.

|`python3 scripts/wfc_op.py status "$ATTEMPT"`
|link:{operator-docs}/operator_manual/ch03_running/02_launch_status.adoc#status[STATUS]:
after successful preparation expect `PREPARED_NOT_LAUNCHED`; after launch
inspect persisted Run facts and
link:{operator-docs}/operator_manual/ch03_running/02_launch_status.adoc#terminal-states[terminal states].

|`python3 scripts/wfc_op.py launch "$ATTEMPT"`
|link:{operator-docs}/operator_manual/ch03_running/02_launch_status.adoc#launch[LAUNCH]:
enter the prepared provider-capable path; the first real dispatch crosses
the provider boundary.

|`python3 scripts/wfc_op.py archive "$ATTEMPT" --dry-run`
|link:{operator-docs}/operator_manual/ch04_evidence/02_archive.adoc#archive[ARCHIVE]:
inspect the canonical archive plan for a terminal Run.

|`python3 scripts/wfc_op.py archive "$ATTEMPT"`
|The same archive owner describes the dry-run-then-real delegation and
preservation of each Run's own truth.
|===

Continue with link:{operator-docs}/operator_manual/ch04_evidence/02_archive.adoc#semantic-ledger[semantic ledger curation].
Any open authority/Finding gap requires a fresh maintainer decision under
link:{operator-docs}/operator_manual/ch03_running/02_launch_status.adoc#terminal-states[stop interpretation]
and link:{operator-docs}/operator_manual/ch06_recovery/01_outcomes.adoc[recovery].
Only then, separately and explicitly, consider
link:{operator-docs}/operator_manual/ch05_self_development/02_promotion.adoc[Runtime promotion]
and push; the command index grants no such authority.
