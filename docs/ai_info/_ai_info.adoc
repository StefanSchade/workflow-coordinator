= WFC task router

Use this router to choose a small current starting set.  It is a task index,
not an authority source and not a substitute for link:../README.adoc[the
authority index].  Open archive material only when a current source explicitly
labels it as provenance or a bounded archaeology question requires it.

[cols="2,3,4",options="header"]
|===
|Need |Open first |Load history only when

|Project context and authority
|link:../../README.md[Repository README], then link:../README.adoc[authority index]
|a current source requests provenance or the applicable Commission requires it.

|Current architecture
|link:../architecture.md[Architecture]
|a current architecture source points to labelled historical provenance.

|Operate, prepare, recover, or promote
|link:../wfc_operator_manual.adoc[Operator manual]
|the task needs a focused procedure: link:../run-preparation.adoc[preparation], link:../self-development.adoc[self-development], link:../run-recovery-and-salvage.adoc[recovery], or the successor-continuation runbook.

|Active work
|link:../backlog/_open.adoc[Active-work manifest]
|the card's controlling source or its labelled provenance is needed.

|Project Memory
|link:../project_memory.adoc[Project Memory orientation], then link:../../project_memory/README.adoc[canonical JSON navigation]
|a canonical record's cited source is needed as evidence.

|Review route
|The current WorkItem/Profile and its named current source
|the current source or WorkItem names a review artifact as provenance.
|===
