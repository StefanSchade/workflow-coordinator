= WFC task router

Use this router to choose a small current starting set.  It is a task index,
not an authority source and not a substitute for link:../README.adoc[the
authority index].  Open archive material only when a current source explicitly
labels it as provenance or a bounded archaeology question requires it.

Current models and operational docs hold distilled understanding of the present
system. Warm holds relevant investigations, unresolved alternatives, active plans
and developing concepts; cold is inactive long-term memory outside normal active
context, including still-valid ideas. Retrieval does not confer current authority:
reconsider conclusions against current sources. See
link:doc_conventions.adoc#_knowledge_homes[knowledge homes] and the exploratory
link:../research/context_sculpting_and_knowledge_lifecycle.adoc[knowledge-lifecycle research].

For local document navigation, run `make doc-catalog`, then for example
`python3 scripts/wfc_doc_catalog.py query --title TEXT` or `query --id ID`
(with the same script). The derived catalog can become stale; regenerate it
explicitly. It grants no authority and raw header declarations are unverified.
Identity searches cover filenames, titles and identity headers, not body mentions;
use full-text search for those. `make doc-catalog-check` reports drift and
informational link and Project Memory source-path misses.

Maintain link:../cold_storage/project_history/README.adoc[the project history]
as work progresses: after a meaningful workstream, accepted milestone, or
relevant backlog/status change, add a concise dated entry or update the
corresponding section, including known commit anchors and FTR/BUG links.
Distinguish proposals, Run outcomes, independent review, and maintainer
acceptance; use the history as non-authorizing provenance. Do not invent a
commit ID for uncommitted work. Update it periodically, not for every Hop.
