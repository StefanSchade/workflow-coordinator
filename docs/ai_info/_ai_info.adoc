= WFC task router

Use this router to choose a small current starting set.  It is a task index,
not an authority source and not a substitute for link:../README.adoc[the
authority index].  Open archive material only when a current source explicitly
labels it as provenance or a bounded archaeology question requires it.

Maintain link:../cold_storage/project_history/README.adoc[the project history]
as work progresses: after a meaningful workstream, accepted milestone, or
relevant backlog/status change, add a concise dated entry or update the
corresponding section, including known commit anchors and FTR/BUG links.
Distinguish proposals, Run outcomes, independent review, and maintainer
acceptance; use the history as non-authorizing provenance. Do not invent a
commit ID for uncommitted work. Update it periodically, not for every Hop.
