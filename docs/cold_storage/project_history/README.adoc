= Workflow Coordinator project history
:toc:
:toclevels: 3

This is a concise, non-authorizing guide to the context around commits, not a
release note or a complete commit list. Dates are author dates from `git log --reverse` unless a conversation or
investigation is explicitly identified. Each section lists the commits in its
consecutive segment of the reachable history through the cut-off, so a short
commit ID can be searched here. A segment may contain small concurrent or
related changes as well as its named workstream; it is a navigation aid, not
an assertion that every commit was produced by that Run. Search the Git log
and follow the cited records for full detail. `Backlog (related)` links the relevant
FTRs and BUGs directly at their historical context; `Backlog (recorded or planned)`
identifies records introduced or planned during that period and
does not assert implementation. Where only a review survives in the archive,
the link leads to that review. Other-branch commits are outside this list, except where explicitly identified
as preserved WIP candidates.

No release has yet been published. The first intended beta is 0.1.0b1;
this account covers the work preceding it through 10 November 2026
(repository HEAD `7316a70`). Future releases can have their own chapters.
Pre-extraction IDs below are the rewritten IDs in this repository; the
link:../sources/pre-0.1.0b1/provenance/incubator-commit-map.tsv[commit map]
relates them to the source repository. Entries pruned during extraction require
the original repository and may not have a retained counterpart.
