= Pre-0.1.0b1 future-concepts archive

Proposals, hypotheses, and target architectures that describe no delivered
functionality, retired for the `pre-0.1.0b1` release. Most such documents
self-declare that they authorize nothing; where an older document does not,
its non-authorizing status follows from its archival classification here,
not from a declaration it originally contained. Its place in this directory
is what stops it being read as a requirement for the current release.

See link:../../README.adoc[the cold-storage README] for the overall convention.
