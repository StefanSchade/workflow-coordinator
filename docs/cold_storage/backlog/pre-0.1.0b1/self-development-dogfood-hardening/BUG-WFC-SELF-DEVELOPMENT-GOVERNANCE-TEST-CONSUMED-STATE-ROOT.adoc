== Observed behavior

The permanent self-development governance architecture test contains both its
isolated prospective-state-root preflight assertion:

----
assert not state_root.exists()
----

and an assertion against the concrete host path for Attempt 5:

----
assert not Path(
    "/home/stefan/wfc-state/"
    "WI-WFC-DEVELOPER-ERGONOMICS-REVIEW-003-20260923-01"
).exists()
----

The latter condition was true before the authorized Attempt-5 Run was started,
but necessarily became false when that Run legitimately created its state root.
After the Run stopped, the maintainer reproduced the full suite provider-free
using the same external development environment: exactly one test currently
failed, this concrete assertion; all other tests passed.

The persisted Coordinator trusted evidence for H002 separately records only
`python -m pytest -q` exit 1 and omits stdout body. It does not identify or
count the test failures. This BUG relies on the stated independent post-run
reproduction for the one-failure classification, not on the agent-authored
exploratory claim of two failures.

== Root cause and intended boundary

A one-time operational pre-launch condition for a specific real Run was
encoded as a permanent repository architecture-test invariant. This is a
lifecycle/category error in the test, not evidence that fresh-state-root guards
are wrong.

The intended distinction is:

* production/preflight mechanics are tested with isolated temporary state roots;
* before a real Run, the maintainer may separately verify that the specifically
  authorized external state root does not yet exist; and
* after a real Run has legitimately started, the permanent test suite must not
  require that historical, consumed external root to remain nonexistent.

== Likely bounded correction

Do not implement the correction in this BUG record.

The likely bounded correction is to retain the isolated
`assert not state_root.exists()` preflight check and remove or otherwise
eliminate the permanent assertion against
`/home/stefan/wfc-state/WI-WFC-DEVELOPER-ERGONOMICS-REVIEW-003-20260923-01`.

This BUG does not authorize removal of fresh-state-root guards from operational
launch procedures or production preflight semantics. It does not authorize a
Run resume/retry, Runtime change, provider invocation, or modification of
Attempt-5 frozen state.
