== FACT -- agent-shell observation is distinct

Inside its own execution environment, the agent ran `python -m pytest -q` and
received `/bin/bash: python: command not found`. It incorrectly treated that
shell result as a blocker for the sole trusted evidence command.

A later provider-free probe established that bare `python` was absent while
`python3` resolved to `/usr/bin/python3` in both the host shell and Codex
sandbox. The Coordinator's external development interpreter was directly
reachable from the Codex sandbox and imported both `pytest` and `yaml`.

INTERPRETATION: these observations do not demonstrate a Python toolchain or
development/evidence-environment reachability defect. They show that the agent
confused optional exploratory shell validation with evidence independently
owned and executed by the Coordinator.

== FINDING A -- phase action authority is not projected clearly enough

Observed effect:: The agent treated the sole permitted exit route, `review`, as
if it prohibited implementation in the current `investigate` phase.

FACT:: The profile gives `investigate` the authorized actions `edit` and
`commit`, while its `review` route specifies the successful Hop exit. A route
describes how a Hop exits; it does not replace the current phase's mutation
authority. The Coordinator admits and enforces `authorized_actions`, but the
agent-facing prompt header projects phase, authorized scope, permitted routes,
and evidence without projecting `authorized_actions`.

FUTURE CORRECTION:: Consider a bounded change that projects
`authorized_actions` and explicitly distinguishes current-Hop actions from
exit routes. This artifact neither implements nor accepts that correction.

== FINDING B -- Coordinator trusted-evidence ownership is insufficiently explicit to the agent

Observed effect:: The agent reran the authored evidence command in its own
shell, found bare `python` absent, and escalated despite separately passing
Coordinator trusted evidence.

FACT:: The operating contract says that agent-reported validation or test
results are not Coordinator-trusted evidence, but it does not explicitly say
that declared evidence is executed separately by the Coordinator and need not
be reproducible in the agent shell.

FUTURE CORRECTION:: Consider a bounded clarification of Coordinator-owned
evidence semantics, including the distinction between optional agent-side
exploratory validation and trusted evidence. This artifact neither implements
nor accepts that correction.
