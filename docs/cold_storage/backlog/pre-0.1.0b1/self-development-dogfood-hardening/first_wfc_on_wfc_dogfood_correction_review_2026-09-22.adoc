`test_legacy_v1_contract_bytes_cannot_pass_the_v2_digest` reconstructs the
historical V1 text from current V2 text and asserts the result hashes to the
hard-coded `LEGACY_V1_SHA256`. The invariant is genuine, not tautological:

* the comparison target is a hard-coded constant, never a value derived from
  the current text, so the reconstruction cannot define its own success;
* `LEGACY_V1_SHA256` was verified against real history -- `git show
  76d88fa:...agent_operating_contract_v1.txt` hashes to exactly
  `058fde86...` at 1688 bytes;
* the reconstruction was executed in isolation and diffed against the actual

invariant. A digest-only fixture would be a defensible alternative but is not a
finding.

== INFO/WATCH

INFO/WATCH 1 -- promotion build hygiene, not a defect in this commit.
The untracked, gitignored `build/lib/workflow_coordinator/resources/` in the
development worktree still holds a stale `agent_operating_contract_v1.txt` from
before the rename. Setuptools' legacy `build/lib` staging directory does not
prune deleted files, so a wheel built from this dirty tree ships both V1 and
V2. Confirmed empirically: installing from the worktree shipped both; installing
from a pristine `git archive` export of the same commit shipped only V2, and
provenance was V2 in both cases because the loader names V2 literally and
digest-verifies. Runtime selection is therefore never ambiguous, so this is
hygiene rather than an authority defect. Because promotion proceeds by export
and non-editable install, the maintainer should export from a clean tree or
remove `build/` before building the next Runtime N.

INFO/WATCH 2 -- duplicated resource filename literal, pre-existing.
`prompt.py:19` defines `RESOURCE` while `prompt.py:54` repeats the filename as
a literal inside the loader. Divergence is currently caught by
`test_a3_resource_identity_and_provenance_are_exact`, which reads through
`prompt.RESOURCE` and compares the bytes to the loaded contract, now reinforced
by the single-resource assertion. Pre-existing under V1 and adequately guarded;
no action required.
