== 2. Adversarial review method

The rereview compared the correction with the actual source selection and
admission seams at the reviewed HEAD, then attempted to preserve the F004
counterexample: pin the component manifest at one commit, change only the
Simple modifier bytes at expected HEAD, and allow those changed bytes to enter
the dispatched prompt.

The relevant current behavior is:

* `render_commission` traverses only every phase's `components.role`, preserves
  first-reference order through `dict.fromkeys`, and uses that truncated set for
  both component source digests and `sources.selected_components`
  (`src/workflow_coordinator/commissioning.py:442-460`).
* Runtime `_selected_ids` traverses every phase and, within each phase, role,
  modifier, then repository-policy components, also deduplicating in first-
  reference order (`src/workflow_coordinator/operator.py:107-112`).  Preflight
  loads every such selected component from expected HEAD and makes it a
  governing input (`operator.py:437-446`).
* `verify_render_manifest` rerenders from pinned sources and byte-compares the
  five rendered targets, but its reused-input loop can compare only the
  component-manifest path and the selected-component paths the renderer put in
  the manifest (`commissioning.py:490-518`).

Therefore the defect is neither in prompt assembly nor in the pinned-blob loop.
It is the renderer's incomplete input set.  The correction targets that exact
seam: design lines 281-290 require a deterministic phase traversal of `role`,
`modifiers`, then `repository_policy`, with first-reference deduplication, and
require the existing digest and manifest generation to consume the complete
set.  That ordering matches `_selected_ids`, so there is no second component
selection definition with different semantics.

== 3. Finding disposition

=== 3.1 F004 -- every closed Simple prompt component is source-pinned

Disposition:: *Resolved.*

Invariant:: Every prompt component supplying closed Simple programme behavior
is recorded in the render manifest with its pinned-source digest and is byte-
compared against the Intent's pinned component source object before admission.

The corrected design satisfies the invariant in four independently enforceable
parts:

. It now documents the current mismatch rather than claiming protection that
  does not exist (`design:56-66`).
. The implementation prescription expands only the existing
  `render_commission` traversal to all three component categories already used
  by runtime selection, and makes the existing source-digest and
  `selected_components` producers consume that same ordered set
  (`design:279-290`).
. The trust-boundary section explicitly retains rerendering, rendered-bundle
  equivalence, and the current reused-component pinned-blob comparison before
  canonical preflight (`design:341-364`;
  `commissioning.py:490-539`).
. The negative test uses the original counterexample: a pinned component
  manifest plus modifier bytes that differ between
  `components_ref.source_commit` and expected HEAD must be rejected before
  operator dispatch (`design:366-381`).  It additionally requires every
  selected category to be rendered and byte-checked.

The correction is minimal.  It adds no second manifest, pinning service,
admission phase, or prompt registry.  The existing pinned-source read supplies
the digest; the existing manifest record carries it; and the existing Front
Door loop performs the expected-HEAD-versus-pinned-object comparison.  The
current Direct-v1 and Robust-v1 catalogue records have empty `modifiers` and
`repository_policy` lists in every phase, so the specified byte-identical
render-manifest regression is concrete rather than aspirational.

The counterexample can no longer pass under the proposed design: once the
Simple modifier path is in `sources.selected_components`, its changed expected-
HEAD bytes fail the existing comparison at `commissioning.py:514-518` before
`_preflight` is called at `:519-539`.  This closes F004 without changing the
one-invocation lifecycle or trusting the Worker's self-assessment.
