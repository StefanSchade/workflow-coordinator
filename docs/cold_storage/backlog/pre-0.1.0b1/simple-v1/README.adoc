== Immutable governance provenance

`governance/workflow-programs/simple/v1.yaml` records the design and
broad-review paths above, as they were, in its `source:` field. That field is
hand-authored provenance text, read by the compiler and then discarded
(`commissioning.py`'s `semantic_program.pop("source", None)`) before the
pinned program is structurally validated -- it is never resolved as a
filesystem path at runtime. An accepted programme revision is never edited in
place, so this field is intentionally left stale rather than corrected; this
README is where the current location is recorded instead.

See link:../../../README.adoc[the cold-storage README] for the overall convention.
