== New INFO/WATCH

INFO/WATCH 6 -- promotion must build from a clean export.
The architecture guard inspects the *source tree* resource directory, because
`pythonpath = ["src", "."]` makes in-process imports resolve to `src/`. It
therefore cannot observe a stale resource that exists only in build output or
in an installed copy. Setuptools' legacy `build/lib` staging directory does not
prune deleted files, so a wheel built from a worktree that still carries a
pre-correction `build/` would ship V2 alongside V3 while the guard stays green.
No such directory exists right now, and the pristine export was verified to
ship only V3, so this is promotion hygiene rather than a defect in `c6e3f245`.
The maintainer should promote by pristine export, as the prior promotion did.
