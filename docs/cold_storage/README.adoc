= Cold storage

Cold storage is inactive long-term memory outside normal active context. It
preserves earlier understanding and history, original concepts and rationale,
rejected approaches, completed investigations and reviews, valid but currently
irrelevant ideas, parked plans and provenance. Inactive does not mean invalid
or obsolete. This is not normal orientation reading or current authority.

Current knowledge is distilled understanding needed to understand, maintain,
develop and operate the present system. Warm holds relevant investigations,
unresolved alternatives, active planning and concepts in development; a review
can remain warm while it supports that work. See
link:../ai_info/doc_conventions.adoc#_knowledge_homes[knowledge homes] and the
exploratory link:../research/context_sculpting_and_knowledge_lifecycle.adoc[lifecycle research].

== Selective retrieval

Start from a labelled provenance link in a current source or a bounded question.
Use the existing release/workstream group below, the
link:project_history/README.adoc[narrative history] for chronology, or the
link:sources/pre-0.1.0b1/README.adoc[source archive] for original sources. For
example, the source archive leads to the
link:sources/pre-0.1.0b1/claude_code_adapter_architecture.adoc[Claude adapter snapshot through 2026-11-10];
it supplies that earlier understanding, not today's adapter contract.

Opening or retrieving a cold source does not automatically reactivate it or
confer current authority. Reconsider useful conclusions against current sources
before using them as guidance. Return to the link:../README.adoc[authority index],
link:../ai_info/_ai_info.adoc[task router] and
link:../backlog/_open.adoc[backlog overview] for current direction.

== Structure

Material is organized by category, then by release:

[source,text]
----
cold_storage/project_history/pre-0.1.0b1/  narrative chronology and release navigation
cold_storage/sources/pre-0.1.0b1/          imported history and provenance snapshots
cold_storage/backlog/pre-0.1.0b1/<group>/   completed feature and workstream material,
                                             grouped: FTRs, BUGs, concepts, designs,
                                             reviews, and closure evidence for one
                                             finished workstream, together
cold_storage/architecture/pre-0.1.0b1/      historical architecture discussion spanning
                                             several features, distinct from the current
                                             ../architecture.md
cold_storage/future/pre-0.1.0b1/            proposals, hypotheses, and target
                                             architectures describing no delivered
                                             functionality; never read as requirements
                                             for the current release
----

The release segment (`pre-0.1.0b1/`, then `0.1.0b1/`, ...) repeats for each
future release, so the convention does not change as the project moves
forward.

== Migration status

This is the *target* structure, not a completed migration. The following
directories predate this convention and remain valid and in active use until
their contents are migrated into the structure above:

* `cold_storage/backlog/history/`
* `cold_storage/concepts/history/`
* `cold_storage/concepts/reviews/`

A document living in one of these directories is not thereby misplaced,
missing, or superseded.
