= Cold storage

Cold storage preserves completed, superseded, rejected, and review material as
available evidence.  It is never current authority and is not normal
orientation reading.  Load it only through a labelled current provenance link
or for a bounded archaeology need; use the authority index, task router, and
active-work manifest for current direction.

== Structure

Material is organized by category, then by release:

[source,text]
----
cold_storage/project_history/pre-0.1.0b1/  narrative chronology and release navigation
cold_storage/sources/pre-0.1.0b1/          imported history and provenance snapshots
cold_storage/backlog/pre-0.1.0b1/<group>/   completed feature and workstream material,
                                             grouped: FTRs, BUGs, concepts, designs,
                                             reviews, and closure evidence for one
                                             finished workstream, together
cold_storage/architecture/pre-0.1.0b1/      historical architecture discussion spanning
                                             several features, distinct from the current
                                             ../architecture.md
cold_storage/future/pre-0.1.0b1/            proposals, hypotheses, and target
                                             architectures describing no delivered
                                             functionality; never read as requirements
                                             for the current release
----

The release segment (`pre-0.1.0b1/`, then `0.1.0b1/`, ...) repeats for each
future release, so the convention does not change as the project moves
forward.

== Migration status

This is the *target* structure, not a completed migration. The following
directories predate this convention and remain valid and in active use until
their contents are migrated into the structure above:

* `cold_storage/backlog/history/`
* `cold_storage/concepts/history/`
* `cold_storage/concepts/reviews/`

A document living in one of these directories is not thereby misplaced,
missing, or superseded.
