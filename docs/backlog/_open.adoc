This is the sole active-work manifest: current priority, readiness, and
dependency between items. It grants no execution authority; a separately
authorized Commission, WorkItem, Profile, and Policy remain necessary for
execution. Each item links to its one controlling source rather than
restating it; see link:README.adoc[the backlog index] for that convention.

== Release sequencing

Projected Result Contracts P1-P3 are delivered and Runtime-promoted; P3.5 is
designed but its implementation is held behind the Front Door Runtime/
Profile/Commission boundary refactor, which is itself in progress (contract
design accepted; `direct@v1`/`robust@v1` implemented; the former
Run stopped before a recorded acceptance and the latter was independently accepted). P4 and P5 are conditional on P3.5/Front-Door context and are not
assessed until then. For the Level-0 Beta-MVP release gate: `simple@v1` and
the Claude Code adapter are delivered MUST-HAVEs; token-consumption evidence
is the one remaining undelivered MUST-HAVE. Front Door Stage 2, the
`.wfc/archive/` schema, and the Commission test-burden investigation are
each explicitly deferred until Stage-1 usage evidence exists.
