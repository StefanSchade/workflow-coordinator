== Open blocking implementation requirement

=== S1-IR-001 -- Reduction must reject reassessment of an already assessed correction Hop atomically

Underlying invariant:: Each corrector coverage record has exactly one next
evaluator assessment. Result reduction must enforce the same single-use
correlation accepted by the durable Run-v3 parser, before any Finding mutation
or route application, so every admitted Run remains persistable and replayable.

`_validate_convergence_records_before_apply()` currently builds
`prior_correction_hops` from every prior Hop with coverage and unconditionally
selects the latest one. It does not remove or reject correction Hop IDs already
named by an earlier convergence assessment. A later evaluator can therefore
reuse that correction Hop ID, pass totality and matching-delta validation,
mutate the Finding, persist another assessment into the in-memory Hop summary,
and take an autonomous route. In contrast, `_validate_v3_run()` explicitly
tracks assessed correction Hop IDs and rejects the second use. This makes
reducer acceptance and authoritative wire validation disagree.

The defect is observable at:

* `src/workflow_coordinator/reducer.py`, the prior-correction selection and
  assessment correlation around lines 626-646; and
* `src/workflow_coordinator/serialization.py`, the Run-v3 single-use check
  around lines 1209-1215.

Required correction:

. Before applying any result-v2 delta, derive the correction Hop IDs already
  assessed by prior accepted Hop summaries and reject reuse of any such ID.
. Keep selection/correlation deterministic: an evaluator may assess only the
  current unassessed correction Hop that its claims name; it may not fall back
  to an older already consumed coverage record.
. Preserve transactionality. Rejection must leave Findings, Hop convergence
  records, IDs, and route state unchanged.
. Add a focused reducer regression that performs one valid assessment, attempts
  a second assessment of the same correction Hop, and proves fail-closed state
  with no route application. Also prove that a later distinct corrector Hop can
  still be assessed normally and persists through `run_to_json()`.

This correction fits the already authorized `reducer.py` and
`tests/unit/test_reducer.py` paths. No scope or semantic-authority expansion is
required.
