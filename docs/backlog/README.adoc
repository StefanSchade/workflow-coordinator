= WFC backlog

The link:_open.adoc[active-work manifest] is the sole current backlog view.
It records intent, current source ownership, and ordering; it does not
authorize a Run.  Execution still requires an applicable Commission, WorkItem,
Profile, and Policy.

The manifest groups items by readiness -- implemented and accepted;
implemented with outstanding review findings; ready to commission; planned,
not yet ready; or deferred/post-MVP -- not execution authority.  Full
technical scope and acceptance content remain in the one linked active
BUG/FTR source (or the one tightly coupled roadmap-family card).
Completed sources, their reviews, and other closure evidence are grouped by
workstream under `../cold_storage/backlog/pre-0.1.0b1/<group>/` as
non-authorizing provenance, not a competing roadmap; see
link:../cold_storage/README.adoc[the cold-storage README] for the convention.
Material not yet migrated into that structure remains under
`../cold_storage/backlog/history/`.
