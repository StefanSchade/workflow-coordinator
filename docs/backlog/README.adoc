= WFC backlog

The link:_open.adoc[active-work manifest] is the sole current backlog view.
It records intent, current source ownership, and ordering; it does not
authorize a Run.  Execution still requires an applicable Commission, WorkItem,
Profile, and Policy.

`NOW`, `NEXT`, `LATER`, and `WATCH` describe current disposition, not execution
authority.  Full technical scope and acceptance content remain in the one
linked active BUG/FTR source (or the one tightly coupled roadmap-family card).
Completed sources are under `../cold_storage/backlog/done/`; reviews, stop
records, and other archaeology are under `../cold_storage/backlog/history/` as
non-authorizing provenance, not a competing roadmap.
