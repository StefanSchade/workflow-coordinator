= Standalone backlog

This backlog records intent and ordering. It does not authorize a Run. The
disposition vocabulary is `NOW`, `NEXT`, `LATER`, `WATCH`, and
`DROP / SUPERSEDED`.

  pending independent acceptance. Slice B2 is not implemented.

== NEXT

`NEXT` is ordered intent, not execution authority.
