== Core idea

A bounded investigation/experiment task does not have the same shape as an
ordinary implementation task. A candidate choreography, recorded here only
as illustrative, not as a committed topology:

----
hypothesis formation
    |
    v
experiment design
    |
    v
execution
    |
    v
observation
    |
    v
interpretation
    |
    +-- sufficient -- report / conclude
    |
    +-- insufficient -- follow-up experiment (back to experiment design)
----

== Essential property

A negative or inconclusive experiment is not a failed workflow. Ordinary
implementation/review workflows treat "no defect found, nothing to fix" as
success and an open Finding as the thing that drives another iteration; an
investigation's value is in what was actually learned, whether or not that
learning is a clean positive result. Iteration in this workflow arises from
new insight (a result that changes what is worth asking next), not
necessarily from a Finding in the existing sense. A design that routes every
iteration through Finding disposition risks force-fitting an investigation
into an acceptance model it does not actually have.

== Open questions this record deliberately does not resolve

* Whether this becomes a new workflow programme (a fourth sibling to
  `direct`/`robust`/`simple`) or is expressible as additional roles/phases/
  transitions within an existing one. No preference is recorded.
* What role, if any, plays the part independent review plays in
  `robust@v1` -- adversarial verification, a second independent
  interpretation, or something else entirely.
* What a durable artifact for this workflow looks like, and whether
  today's `durable_artifact: required/optional/none` vocabulary is
  sufficient.
* How "sufficient to conclude" is determined, and by whom.

== Non-goals (for this record)

This record does not itself: design a workflow programme or profile;
propose a schema, phase, or role; decide product scope; or authorize any
implementation. It exists to preserve the idea and its one essential
property (above) against loss, not to settle how it would be built.
