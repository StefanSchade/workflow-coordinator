=== 7.1 The four-Hop budget cannot produce an unauthorized H005

This was verified against production reducer and driver semantics, not inferred
from the YAML.

`_preflight` and `_admit_a1` pin `hop_limit = 4` (WorkItem 4, not above policy
4, not above the engine hard maximum 5). The mandatory sequence consumes
H001..H004. The dangerous case is a `correct` result *from* `rereview` at H004.

Three independent production mechanisms stop it:

. `reducer.reduce_result`:
+
[source,python]
----
invocation_needed = route.supervisor or route.effect is RouteEffect.GOTO
if invocation_needed and updated.hop_used >= updated.hop_limit:
    -> RunStatus.AWAITING_HUMAN_BUDGET, stop_reason="autonomous_hop_budget_exhausted"
----
+
At H004, `hop_used == hop_limit == 4` and `correct` is a `goto`, so the Run
leaves `READY` for `AWAITING_HUMAN_BUDGET` *before* any route is applied.

. `operator.run_serial_hops` loops only `while run.status is RunStatus.READY`
  and additionally breaks on `run.hop_used >= run.hop_limit`. A non-`READY`
  status terminates the loop, so no fifth invocation is constructed.

. `model.record_hop` raises `autonomous Hop budget exhausted` if a fifth Hop is
  ever attempted, and `slice4.dispatch_eligible` gates the provider-capable
  boundary on `status == "ready" and hop_used < hop_limit`.

The `accept` route is `complete`, so `invocation_needed` is false and the budget
check is correctly bypassed; `_apply_route` still refuses completion while any
blocking Finding remains `open`.

*Result: no fifth Hop can exist, and no fifth Hop can be provider-capable.*

== 8. Review-artifact separation

The central least-authority invariant is

[source,text]
----
review-artifact mutation authority  !=  implementation mutation authority
----

and it follows from production admission and Git semantics, not from prose.

*Landing a commit.* `vertical.run_one_hop` calls

[source,python]
----
trusted_commit(..., allowed_paths=phase.authorized_scope, intent=result.commit_intent, ...)
----

and `git_facts._validated_intent_paths` raises
`commit intent path is outside authorized scope` for any path not contained in
the *current phase's* scope. The agent never runs Git itself; the operating
contract forbids `git add`, `git commit`, `git push`, `git reset`, `git clean`,
`git rebase` and `--amend`, and only this trusted path can materialize a commit.

*Observing the worktree.* Whether or not a commit intent exists,
`git_facts._observe_hop` runs with the same `phase.authorized_scope` and emits
`out-of-scope changed path: <p>` for any changed path outside it, plus
`dirty tracked state` / `non-ignored untracked state` for uncommitted mutation.
Those become `MechanicalFacts.repository_anomaly`, which `reduce_result`
preempts on before any Finding or route authority is exercised.

Applying that to the four phases:

* The *reviewer* may commit `docs/backlog/first_wfc_on_wfc_dogfood_review.adoc`
  during `review`: the path is the phase scope, the phase holds `edit` +
  `commit`, and `run_one_hop`'s `review_artifact_commit` branch admits a
  `changes_required` commit intent whose paths are a subset of the phase's
  durable artifacts.
* The *reviewer cannot* mutate the six implementation paths: they are outside
  `review.authorized_scope`, so `trusted_commit` refuses and `observe_hop`
  flags any worktree change.
* The *developer/corrector* may mutate the six implementation paths and *cannot*
  mutate the review artifact, which is outside `investigate`/`correct` scope by
  the same two mechanisms.
* *Rereview mutates neither.* It holds neither `edit` nor `commit`, so a
  non-null commit intent hits `missing_actions` and fails closed *before* Git is
  touched; and any uncommitted change is caught as a repository anomaly, since
  `observe_repository` cleanliness is also re-checked post-evidence.

`_preflight` additionally requires every mapped durable artifact to lie within
both the WorkItem scope *and* the owning phase's scope, so the review artifact
cannot be mapped to a developer phase.

*Result: scope separation is enforced by production semantics.*
