== Decisions it implements

D6 (Option A). `python-compat` becomes a numbered gate *G9*: it is added to the
`needs:` of `publish-testpypi`. The advertised CPython 3.10-3.13 stays. Accepted
risk (maintainer, 2026-11-25): the 3.10-3.12 jobs install from the ordinary
index, not from the offline bundle, so an index or upstream change can turn
a release red. Response is a re-run of the failed jobs (nothing was uploaded
yet), never a re-tag; the chapter's recovery table already says so for a
failure before any upload. Dropping 3.10 later is a maintainer change (the
classifier, the matrix entry, optionally `requires-python`).

D3. `.github/dependabot.yml` for the `github-actions` ecosystem with a cooldown
for new versions. Automerge applies only to actions that run exclusively in
the unprivileged `check` and `python-compat` jobs (today `actions/checkout`,
`actions/setup-python`, `actions/upload-artifact`), limited to minor and patch
updates. Actions that run in `publish-testpypi`, `publish-pypi` or `release`
(`actions/download-artifact`, `pypa/gh-action-pypi-publish`) are reviewed by
hand. Residual risk to state in the record: an action in the `check` job still
influences the bytes that are later published (it builds and uploads the
candidate), so automerge there is *lower* risk, not none; the human `pypi`
approval and the audited, hash-listed artifact bound it. The slice delivers the
file and the documentation; whether and when auto-merge is switched on is the
maintainer's setting, recommended only after the first manually reviewed
Dependabot run.
