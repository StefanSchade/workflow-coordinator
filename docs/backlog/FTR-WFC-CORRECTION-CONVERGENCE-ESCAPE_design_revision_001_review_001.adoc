== Open blocking design requirement

=== DR1-IR-001 -- Current-Hop qualification, final-Hop correlation, and publication are circular

Underlying invariant:: A live convergence decision and replay from its durable
authoritative inputs must agree about whether the current evaluator cycle
qualified. No persisted escape decision may depend on a mechanical pass that
the post-crash authoritative input set cannot reproduce.

The proposed schema-4 attempt is not publishable until after reduction. Its
mandatory `hop_summary_sha256` covers the complete persisted HopSummary, and
the exact-correlation rule additionally compares semantic outcome, repository
anchors, commits, and role. The complete HopSummary includes reduction-owned
facts such as the applied route and stop reason. In the current execution
order, `vertical.run_one_hop` executes and validates trusted observations and
calls `reduce_result`; `slice4.run_real_one_hop` then persists the reduced Run
and checkpoint; only after that returns does `operator.run_serial_hops` build
and publish the execution-evidence attempt. The revision's own publication
sequence preserves that Run-before-evidence order.

That order is sufficient for a later Slice-2 read projection, but it is not
closed over the accepted architecture's later evaluator-boundary escape
decision. The revision says Slice 3 must supply the same validated
qualification index before considering escape substitution. For the current
evaluator Hop, no such schema-4 row can yet validate: the row needs the final
HopSummary digest, while the final HopSummary route depends on the convergence
decision that would consume the row.

Both apparent interpretations violate the revised contract:

* Treating the not-yet-published row as missing makes the current evaluator
  cycle non-qualifying. There is no later reduction of that same Hop after the
  operator publishes evidence, so goalpost routing is delayed or omitted.
* Letting reduction use the transient observations as an implicit current-Hop
  pass can select and persist an escape route. A crash after the Run snapshot
  is published but before the schema-4 replacement then leaves that cycle
  unqualified under replay, even though its persisted route was chosen because
  it qualified live. The document explicitly says this crash loses mechanical
  qualification, but it does not reconcile the already persisted semantic
  routing decision.

The checkpoint rule does not repair the mismatch. Rejecting or rebuilding a
stale checkpoint can reproduce the zero-count fact after the crash, but it
cannot undo or justify the route already recorded in authoritative Run
history. This is therefore not merely a cache-publication detail.

Required correction:

. Define the exact trusted input used for the in-flight evaluator Hop and how
  it composes with already durable qualification rows. State whether it is a
  staged attempt, a bounded transient overlay, or another representation, and
  prove that it uses the same plan/Observation conjunction as replay without
  granting semantic authority to evidence machinery.
. Remove the final-Hop-digest/route-decision cycle. Define a stable correlation
  anchor available at the point the live predicate is consumed, or define an
  ordering/commit protocol in which the evidence can become durable before the
  semantic route that depends on it. Do not weaken exact Hop/invocation
  correlation and do not introduce a mutable qualification counter.
. Define the authoritative outcome of every crash and write-failure boundary:
  before qualification publication, after qualification publication but
  before Run publication, after Run publication but before evidence
  publication if that ordering remains possible, and before checkpoint
  regeneration. A recovered/replayed Run must not retain a convergence escape
  that its authoritative qualification input excludes.
. Amend the Slice-3 consequence and future implementation scope to name every
  seam required by the chosen ordering. If `vertical.py` or `slice4.py` must
  stage, correlate, or publish the current attempt, the claimed closed
  production union cannot continue to omit it.
. Require deterministic tests for a current evaluator cycle that reaches the
  goalpost live and on replay, plus injected crashes/write failures at each
  publication boundary. The tests must show identical qualification and route
  justification, absence of partial qualification, and fail-closed recovery.

This correction does not require choosing family A or merging semantic and
mechanical authority. It requires family B to specify a complete live-to-durable
protocol rather than only its post-publication read model.
