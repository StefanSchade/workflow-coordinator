  (`:16`). The second (`:22`) is on the fixture parameter line, where ruff

  configuration ignore is explicitly withheld; `request.getfixturevalue` or a
  conftest move would add mechanism and touch files outside scope. I therefore
  read the criterion as satisfied and, as H002 did, flag the wording for the
  maintainer rather than waive anything: if exactly one directive is wanted,
  that is a decision about the criterion, not about this candidate.
. *`ruff` is unpinned in CI* (`ruff>=0.6`), so a future release can introduce
  findings on an unchanged tree -- the same class of surprise this WorkItem
  just absorbed. Pre-existing and outside this WorkItem's authority; worth the
  maintainer's attention separately.
. *The record is 203 lines*, slightly beyond "keep it compact", and the two
  review artifacts together are longer than the change. Every section earns
  its place and I propose no cuts.
. The two `noqa` comments push lines `:16` and `:22` past `line-length = 100`.
  Inert: `E` is not selected, that file is not in the `format-check` list, and
