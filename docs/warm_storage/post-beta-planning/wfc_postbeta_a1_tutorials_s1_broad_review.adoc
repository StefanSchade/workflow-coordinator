criterion masks it; the Commission's DO (1) nevertheless requires the rule
"as the FTR words it", and the FTR words it with passthrough
(`+<<anchor>>+`, FTR lines 96–99).
+
*Feasible correction, one token pair:* wrap the literal in AsciiDoc
passthrough plus signs inside the backticks, exactly as the FTR does in its
own `The link rule and its guard` section. Nothing
else in the paragraph changes. After the fix, re-run AC-3 and confirm the
file renders with no dangling in-page ref.
