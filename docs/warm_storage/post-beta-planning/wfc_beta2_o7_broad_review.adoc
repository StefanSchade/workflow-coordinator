=== 6. Simplicity and maintainability

The slice is, on balance, *simplifying*: it removes a per-program
`evidence_profiles` indirection and the "exactly one evidence profile"
internal invariant, and it replaces a literal-tuple coupling between a
Commission's content and an admitted workflow shape with a structural
conjunct. The new mechanism is one accumulator plus one grouping function in
the CLI, one sequence parser in the request, one loop in the probe and one
loop in `evidence.py` at the single existing execution site. No new status,
no new schema version, no new state, no second source of truth. The two
places I looked hard at for unnecessary mechanism:

* the `not_executed` projection is a projection-level marker with no runner
  able to produce it, which is the cheaper of the two options the Design
  weighed, and it is what prevents a report from reading as if later gates
  had passed;
* the `required_evidence` plan on the legacy record is additive, opaque to
  the legacy parser, and tolerated when absent.

Both are proportionate. The one piece of avoidable state is N-1 below.
