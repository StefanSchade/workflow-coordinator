= Input pack for the project-history maintenance of 2026-11-27

Standing:: Input material, *not authority*. It was assembled on 2026-11-27 to
feed the Commission that brings the project history
(`docs/cold_storage/project_history/post-0.1.0b1/`) up to date for the period
after the last maintenance event, commit `e9b120e` (24 November 2026, 09:00
local time). Nothing in this pack is a decision, an authorization or a
statement that a Run was accepted; every factual claim a history chapter takes
from it must be re-verified against Git (and, where Git cannot show it, marked
with its source and its confidence).
Contents::
* link:01_maintainer_view.adoc[01 Maintainer view] -- the maintainer's own
  framing and the reason for the fact-anchoring requirement.
* link:02_external_llm_draft.adoc[02 External LLM draft] -- a reconstruction
  draft written by an external LLM chat from the same sources, preserved
  verbatim, with the operator's verification notes.
* link:03_orchestrator_fact_pack.adoc[03 Orchestrator fact pack] -- dated
  anchors (WorkItem to commits, the Run ledger, human interactions) and the
  commands that recompute them, from the Level-1 orchestrator (a Claude Sonnet
  session), who is also a subject of the period.
Provenance and bias:: Two of the three documents were written by participants
in the events (the maintainer; the Level-1 orchestrator) and one by an external
LLM from secondary sources. The history chapters must keep these perspectives
attributed and must not average them into an unattributed narrative.
After use:: Once the history chapters are accepted, this pack may be archived
under cold storage with the other inputs of the project history.
