=== 2. The corrected test -- independently re-derived

The H003 summary reports that `test_probe_runs_the_whole_declared_sequence_in_declared_order`
originally asserted only `["lint", "format-check", "task-check"]` and was
strengthened to assert `declared * 2` plus `result.classification ==
"completed"`, because driving the whole lifecycle for `simple@v1` records
the sequence twice: once as the pre-launch baseline probe, once as the
task-check of the one Worker Hop `simple@v1` runs. I did not take this on
trust; I re-derived it from the two modules that actually produce the
behaviour:

* `frontdoor/lifecycle.py:478-525` (`_do_probe`) iterates `request.evidence`
  in order before any provider starts, appends `probe_passed` on success,
  and only a probe miss causes `_do_probe` to run (`lifecycle.py:1112-1114`
  reuses an existing `probe_passed` journal record if one is already
  there) -- so the probe runs exactly once per Run.
* `simple@v1`'s one phase (`implement`) carries `"evidence": "E"`
  (`commissioning.py` template), so `compile_commission` fills its
  rendered `evidence` list with the identical `evidence_names` tuple
  (`:355-356`); the Worker Hop's task-check then runs that same list again
  at the one phase `simple@v1` has.

Two runs of the identical three-command sequence, in the identical declared
order, is therefore the correct and only possible outcome for a
`simple@v1` Run that reaches `completed` -- exactly what the corrected
assertion pins. The correction is in the strengthening direction (the prior
assertion only checked the probe's prefix, silently discarding the
task-check's own repetition of the same evidence), not a weakening; no
expectation was relaxed, skipped or deleted.

I could not re-execute this test myself to a clean pass in this Hop's own
sandbox: there is no `pytest`/`ruff` here and no network. A leftover venv
from an unrelated historical review Hop (`/tmp/wfc-review-h002-venv`) has
`pytest` and `ruff` installed, but its non-editable `workflow_coordinator`
install is stale (predates even `--execution-bindings-sha256`, a flag from

agent-local environmental limitation, not a reproduced defect: the
structural argument above is independent of execution, and the
