*Invariant restated:* an unresolvable `wfc` executable must be answered with
return code 2 and nothing created, before the scenario's single-use
worktree/branch is burned.

*Correction present:* `2fa7c61` adds `_check_wfc_available()` (a
`wfc --version --json` probe, raising `PreconditionError` on an `OSError` or
a non-zero exit) and a `shutil.which("git")` check, both inside
`_check_preconditions()`, which runs strictly before `_create_worktree()` in
`rehearse()` (`examples/consumer-demo/rehearse.py:66-91`, `:168-170`). The
regression test added in the same commit
(`test_rehearse_refuses_when_wfc_is_not_found_and_a_retry_with_a_working_wfc_still_succeeds`)
covers the `--wfc` path plus a same-scenario retry.

*My own reproduction*, in a workspace made by `make_workspace.py`, outside
the repository tree (`$TMPDIR/wfc-verify-f001`), for all three resolutions
the FTR documents:

* `--wfc /no/such/wfc-binary`: `rehearse.py` prints
  `rehearse.py: could not run \`/no/such/wfc-binary --version --json\`: [Errno 2] No such file or directory: '/no/such/wfc-binary'`
  to stderr and returns *2*. `ls ws/` afterward lists only the five items
  `make_workspace.py` created (no `greeter-run-t1-hello-page`); `git -C
  ws/greeter branch --list` shows only `* main` (no `demo/t1-hello-page`).
  A subsequent call with the same workspace and a working `wfc` then
  succeeds (exit 0) -- the scenario's single lifecycle was not burned.
* `WFC_BIN=/no/such/wfc-binary` (bare `wfc` not given `--wfc`): same message,
  same return code 2, same absence of the worktree and the branch, in a
  second fresh workspace.
* `git` absent from `PATH` (a one-entry `PATH` holding only the `wfc`
  wrapper, in a third fresh workspace): `rehearse.py: \`git\` was not found
  on PATH`, return 2, no `greeter-run-t1-hello-page` created.

All three reproduce the Finding's fix, not just the one the regression test
exercises. The correction's ordering (`git`, then `wfc`, then the marker
file, then the scenario name, then the existing-worktree check, all before
`_create_worktree`) matches the Finding's "feasible minimal correction"
exactly: a reuse of `make_workspace.py`'s own preflight check, no new
mechanism, no behaviour change to the four scenarios. F001 is resolved by
