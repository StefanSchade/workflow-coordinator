=== `F001` resolved: every registered working tree is now a boundary

*Reproduced first, independently, before trusting the fix.* I built a toy
repository with a main checkout and one linked worktree (plain `git`, no
fixture code) and ran `prepare_checkout` at the pre-correction commit
`16b9b8f` through the module directly: `prepare_checkout(repository=<main>,
target=<sibling>/run-checkout)` created a worktree and scratch directory
inside the sibling, leaving `?? run-checkout/` under
`git status --untracked-files=all` in the sibling -- exactly the broad
review's reproduction.

*Then re-ran the identical script at `ff7760e`, both directions:*

* `prepare_checkout(repository=<main>, target=<sibling>/run-checkout, ...)`
  now raises `PreparationRefusal("refused_path_inside_repository")`; the
  sibling's `git status --untracked-files=all` stays empty and
  `run-checkout` was never created.
* The reverse direction, `prepare_checkout(repository=<sibling>,
  target=<main>/run-checkout2, ...)`, refuses the same way; the main tree's
  status stays empty.

This matches the shipped tests
(`test_refuses_a_checkout_path_inside_another_working_tree_of_the_repository`,
`test_refuses_a_checkout_path_inside_the_main_tree_seen_from_a_linked_worktree`,
`test_refuses_a_scratch_path_inside_another_working_tree_of_the_repository`,
`test_registered_working_trees_lists_every_tree_including_the_main_one`), which
I also ran directly (`pytest tests/unit/test_frontdoor_prepare_checkout.py
--wfc-partial`, 54 passed).

The remedy is exactly the "feasible, simpler remedy" the broad review asked
for and no more: `registered_working_trees()` reads
`git worktree list --porcelain -z` once, before the first effect, resolves
each path with `os.fsdecode`; `repository_boundaries()` is that set plus the
resolved top-level and the Git common directory, deduplicated; and
`_require_outside_repository` iterates the set under the *same*
`refused_path_inside_repository` name used before -- no new refusal name, no
new flag, no new state. The old `source.toplevel`/`source.git_common_dir`
comparison is subsumed rather than kept alongside it (`registered_working_trees`
always includes the main tree, and `repository_boundaries` keeps `toplevel`
in the set only as a belt-and-suspenders entry against a disagreement, not as
a second code path). `boundaries` is computed once, ahead of the dirty-base
check's `observe_repository` call and ahead of any path creation, so a
refusal on this ground is still decided before the more specific
`refused_existing_path`/`refused_scratch_inside_checkout` refusals, preserving
the ordering the broad review verified as "the more actionable order".

=== The N-1 fix (non-UTF-8 committed config): independently confirmed, not merely re-described

The broad review's N-1 observation (a non-UTF-8 committed Consumer Config
raised an unhandled `UnicodeDecodeError` instead of `refused_config`) is also
fixed in this Hop, although it was non-blocking. `_git_bytes` now reads Git's
stdout as bytes; `_git_raw` decodes with a named `refused_config` on
`UnicodeDecodeError` rather than `text=True`'s silent exception path; `_git`
is now `_git_raw(...).strip()`. I ran the shipped regression test
(`test_refuses_a_committed_config_whose_bytes_are_not_utf_8`) directly: it
commits a config containing `\xff\xfe` and asserts `refused_config` with "not
valid UTF-8" in the message, rather than a traceback. Pass.

* *N-3* (the transient index-copy exception to "nothing outside the two
  created directories is written") is now qualified in Design decision 3

* *N-4* (the module's private Git helpers duplicate `git_facts`' trusted path
  without its `GIT_*` scrub) now carries one paragraph of rationale on
  `_git_bytes` stating why plain `subprocess.run` is the right call here (this

  repository-local Git hook is not a boundary this command could claim to
  hold). I agree with the judgement: inventing a scrub here would be a
  safeguard addressing a boundary this command does not have in the first
  place.

None of N-2/N-3/N-4 was blocking, and none required new mechanism; recording
one sentence of rationale or qualifying a claim is proportionate to each.
