= Warm storage

Warm storage holds relevant investigations, unresolved alternatives, active
planning and concepts in development, including reviews still serving that
work. Read a document in context, not as a blanket current requirement. See
link:../ai_info/doc_conventions.adoc#_knowledge_homes[knowledge homes].

Ten workstream directories, one level deep, named as the equivalent
link:../cold_storage/README.adoc[cold storage] group would be. A document's
directory is derived from its filename; there is no per-group README.
