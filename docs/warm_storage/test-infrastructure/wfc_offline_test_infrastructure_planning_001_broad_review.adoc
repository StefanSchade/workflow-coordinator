== Attempts to falsify the recommendation

An ambient cache cannot supply a reproducible first install and may still resolve
against an index. Beta-1's provided-environment boundary alone leaves developer
bootstrap and independent WFC build/install regression tests unsolved. Universal
stubbing, shared mutable venvs and disabled build isolation sacrifice relevant
properties. Containers, vendored wheels and mirrors are viable delivery choices
with additional maintenance costs, without current comparative evidence justifying
a new service. The proposal's A1 plus conservative B1 and eventual C is a justified
minimal target; it does not claim measured gains from unperformed fixture designs.

Fresh-checkout provisioning is not circular: a supplied qualified interpreter and
its seed tools can run the standard-library verifier before pytest is installed;
connected acquisition or externally transferred verified bytes precede offline use.
Repository-reviewed hashes/profile, explicit external bundle selection and staged
refresh replace reliance on personal scratch. The profile covers interpreter,
ABI/platform/libc, seed frontend, backend hooks, transitive packages and both
Runtime-N/Development-N+1 metadata. Conflicting closures are not hidden among
unconstrained alternate wheels. Source/transport selection remains an explicit
Maintainer decision rather than an invented dependency service.

Integrity is more than an adjacent checksum file: the plan requires reviewed
provenance, exact artifacts, no unexpected candidates, configuration normalization,
empty-cache runs, failure on stale/missing/corrupt inputs and requalification on
dependency/platform/toolchain changes. It correctly says no-index is not network
denial. Actual denied-network qualification remains mandatory before claiming
offline operation; logs alone do not satisfy it. These mechanisms are proposed
acceptance, not present runtime enforcement.

P1–P3 identify owners, provisional file areas, dependencies, observable negative
cases, clean package probes, retained real-node guards and a measured headroom
target. P4 hands integration to the existing product packages rather than forcing
new product provisioning. The 450-second reference target includes added package
coverage, is proposed engineering acceptance and does not amend evidence policy.
No implementation is authorized by accepting this architecture proposal.
