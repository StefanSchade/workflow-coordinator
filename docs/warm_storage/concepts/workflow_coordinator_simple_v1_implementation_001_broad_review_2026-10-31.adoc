commit handling would still satisfy the current transport test because its
candidate has nothing to commit.

otherwise-valid correlated candidate carrying a non-null CommitIntent and a
matching agent mutation, then prove HEAD is not advanced by a Coordinator

charged, the marker/uncertain Hop remains, and the transport fact is retained
in diagnostics.  Add explicit Direct/Robust render and execution regressions
required by the task.  No production-scope expansion is indicated by this
