adding any other tool allowance. Both fake-executable configuration tests
now require exactly `["Edit", "Write"]`, including with a symlinked repository.
This directly addresses the projected Finding's missing Write authorization.

Independent `claude --version` introspection identifies installed CLI
2.1.270. Its `--help` describes restricted file-tool confinement to working
directories, and automatic denial of actions that would prompt when
`--permission-prompts none` is set. Read-only inspection of its embedded
JavaScript independently confirms the material broad-review observations:
the scrub override selects default mode and recommends explicit allowances;
bare whole-tool matching uses the actual tool name; path-rule matching
excludes rules without path content; Write calls the shared write-permission
check; that check applies restricted-directory confinement before generic
whole-tool approval, which preserves denials. Write's implementation itself
requests parent creation, so the recorded Bash mkdir denial does not
justify approving Bash generally.
