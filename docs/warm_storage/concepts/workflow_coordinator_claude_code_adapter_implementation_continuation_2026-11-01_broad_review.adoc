== 1. Disposition

Verdict:: `changes_required`
Route:: `correction`

The full materialized implementation is not acceptable yet.  The Claude
adapter passes the pathname of `structured-result.schema.json` as the value of
`--json-schema` (`claude_adapter.py:50-56,109-120`).  The accepted design
requires the serialized WFC schema in that argv position (`design:108-119,156`),
and the locally installed CLI's read-only `--help` gives an inline JSON object
as the syntax for `--json-schema <schema>`.  A pathname is not a serialized JSON
schema, so the real CLI will reject or fail to apply this schema before the
intended structured-output path can succeed.

The fake conformance test encodes the same incorrect pathname as its expected
argv and never parses the `--json-schema` argument (`test_claude_adapter_conformance.py:
41-63`).  It therefore makes this transport defect pass.  Correction must pass
the serialized schema object as the flag value and make the fake decode and
assert that inline value, including exact dispatched Run/Hop/Invocation and
permitted-route constraints.  Retaining the small generated schema file for
diagnostics is permitted, but its path is not the flag value.

No other blocking defect was found.  This is a newly reported current-Run
Finding whose authoritative ID is to be allocated by the Coordinator; this
artifact deliberately does not invent one.
