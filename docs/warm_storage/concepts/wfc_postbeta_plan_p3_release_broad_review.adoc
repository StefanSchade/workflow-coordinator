I re-asked the question independently and reach the H002 pass's conclusion. The
plan's expensive options are declined with reasons, not adopted to look
complete: no Pages machinery, no second repository, zero repository secrets, one
workflow file, one implementation of the artifact rule with two callers, the

version) are each argued from a mechanical fact I reproduced, and recorded as
decisions rather than omissions. I found no safeguard that exists only to
exclude a hypothetical, and no state or register the plan adds for its own sake.
