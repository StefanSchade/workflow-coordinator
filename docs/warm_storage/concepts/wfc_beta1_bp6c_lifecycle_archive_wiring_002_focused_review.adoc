=== Non-blocking observations (no Finding)

. `postrun._cached_config` (`postrun.py:82`, called at `postrun.py:194`)
  reads the checkout's cached `commission/config.yaml` outside both new
  guards, so a *removed or malformed cached config* would still raise past
  the post-run step. This is STATE tampering rather than a plausible
  operational input, and it matches the frozen BP4a design, which reads the
  same cached files unguarded at `lifecycle.py:251-253` and
  `lifecycle.py:506` -- a Run whose cached materials are gone already fails
  earlier on the resume path. Correspondingly, the limitations record's
  phrase "caught at every call site that can raise them" is a little
  broader than the code: the guarded call sites are Evidence-settings
  resolution and the archive effect, not the cached-config read.
. Mutant *D3* (removing the pre-existing BP5 refusal "OPS directory is not
  the one recorded in this Run's preparation", `archive.py:688`) survives
  the whole archive plus post-run suite. The refusal and its gap both
  predate this WorkItem; the narrowing only changed how `recorded` is
  derived. Outside BP6c's acceptance list.
. Mutant *C2* (the fake engine stops recording `execution_bindings_source`)
  survives: the fixture change is fidelity, and the mutation-sensitive pin
  for the narrowing is the new unit test. This is the intended division, not
  a gap -- noted so the next reader does not mistake the fixture for the
  pin.
. The `CommissionError` branch returns the cached `ext.archive.result`
  without a recomputed report when a Run was already archived before the
  Evidence configuration broke. No second commit, no untruthful statement;
  the consolidated report is simply not reprinted in that state.
