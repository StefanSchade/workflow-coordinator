== 3. `wfc init` Evidence-repository creation (acceptance case 2)

Independently reproduced outside the test harness (not just by re-running
`test_init_evidence.py`), against three fresh disposable payload/evidence
directory pairs built under `tempfile.TemporaryDirectory()`:

* **Creates a new repository.** `wfc init --evidence-repository PATH` on an
  absent path creates `archive/`, writes the managed `.gitignore` block
  (`archive/**/manifest.json`, `archive/**/run/**`, `archive/**/ops/**`
  between the documented markers), makes exactly one commit
  (`git rev-list --count HEAD` == `1`), configures no remote
  (`git remote` is empty), and prints `NOTHING WAS PUSHED: the Evidence
  repository has no remote configured.` The payload repository's own HEAD and
  working tree are unchanged except the one new untracked `.wfc/` Consumer
  Config directory (`git status --porcelain` == `?? .wfc/`), confirming the
  payload repository is never modified beyond the one file `wfc init`
  already wrote before BP6b.
* **Reuses an existing valid repository untouched.** A second `wfc init`
  pointed at an already-`ensure_evidence_repository`-created path reports
  "reusing existing" and leaves `git rev-parse HEAD` identical to before the
  call.
* **Refuses a foreign non-empty directory before writing anything.** A
  directory containing an unrelated file (no `archive/`, no `.git`) is
  refused with a message containing `refusing`; the directory's listing is
  unchanged (`unrelated-file.txt` only) and no `.git` was created.

All three independently reproduced; see the H001 CommitIntent evidence
script below for the exact commands.

== 4. Retention-aware archive: tracked sets per mode (acceptance cases 3-6)

Independently reproduced with the real `wfc` CLI dispatch
(`frontdoor.cli.main`) against fresh fixtures (not `test_archive_retention.py`'s
own fixtures, built independently with the same shape), and real `git`
subprocess calls (`ls-files`, `status --porcelain`):

* **`local`.** `git ls-files` in the Evidence repository holds exactly
  `.gitignore`, `archive/.gitkeep`, and the one Attempt's
  `.../audit.json` -- no `manifest.json`, no `run/`, no `ops/`. Those raw
  files exist on disk at the destination. `git status --porcelain` is empty.
* **`commit`.** `audit.json`, `manifest.json`, and at least one path each
  under `run/` and `ops/` are all tracked; `git status --porcelain` is empty.
* **`discard`.** The destination directory contains only `audit.json` on
  disk; the tracked set is identical in shape to `local`'s (`.gitignore`,
  `archive/.gitkeep`, the one `audit.json`).
* **`raw_retention=None`.** Reproduced against a plain legacy-style Evidence
  repository (no BP6b-managed `.gitignore` block, built by hand exactly like
  BP5's own fixtures): no `audit.json` is written anywhere, the tracked set
  includes `manifest.json` and `run/operator-plan.json`, and no tracked path
  anywhere ends in `audit.json` -- the unmodified BP5 shape.

== 5. One commit per Attempt, idempotency, crash resume, tamper refusal (acceptance cases 7-9)

Independently reproduced per mode, real Git evidence:

* **One commit per Attempt.** For each of `local`/`commit`/`discard`,
  `git rev-list --count <before>..HEAD` after one archive call is exactly
  `1`.
* **Idempotent re-archive.** A second identical archive call per mode prints
  `ALREADY UP TO DATE` and leaves `git rev-parse HEAD` unchanged (no second
  commit).
* **Crash resume (`local`, `commit`).** `_commit_retention_archive` patched to
  raise after placement, reproducing a kill between placement and commit:
  `git rev-parse HEAD` is unchanged by the simulated crash itself, and a
  follow-up archive call resumes to exactly one commit (`ARCHIVED`,
  `rev-list --count <before>..HEAD` == `1`), not two.
* **Tamper refusal (`local`, `commit`).** After the same simulated crash, a
  placed-but-uncommitted raw file (`run/operator-summary.json`) is tampered
  byte-for-byte length-preserving; the follow-up archive call is refused with
  `does not match its recorded digest` and a non-zero exit code.
* **Different-content refusal (`discard`).** Reproduced via
  `tests/unit/test_archive_retention.py::DiscardRetentionTests::test_different_audit_is_refused_not_overwritten`,
  independently re-read and re-run: changing the underlying Run facts after
  a `discard` archive and re-archiving is refused with `different content`,
  and the placed `audit.json` is left byte-identical to before.
* **Missing/insufficient `.gitignore` refusal (`local`).** Overwriting the
  managed `.gitignore` with an unrelated pattern and re-archiving with
  `--raw-retention local` is refused *before any write*: non-zero exit,
  `does not exclude` in the error, no destination directory created, no
  `.wfc-archive-staging` left behind.
