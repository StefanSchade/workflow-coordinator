== Blocking finding: declaration boundaries contaminate identity

`scripts/wfc_doc_catalog.py` recognizes a definition-list label only when it
contains letters alone. A multiword label therefore falls through to the
continuation branch and is appended to the preceding supported declaration.
In `docs/cold_storage/backlog/pre-0.1.0b1/simple-v1/workflow_coordinator_simple_v1_implementation_001_broad_review_2026-10-31.adoc`,
the `WorkItem` value includes the separate `Run / Hop`, `Reviewed candidate`,
`Reviewed implementation commits`, and other declarations. Consequently
`query --live --id 83ec2b10966392af281dcd22b2cc8a25109d4880` returns that
review even though the hash belongs to `Reviewed candidate`, not its filename,
title, or a supported identity header. Multiword labels similarly contaminate
raw `Status` values in many backlog records. This violates both the bounded raw
declaration and identity provenance requirements. Recognize boundaries for
unsupported labels without incorporating their values, retain legitimate
wrapped values, and add regression coverage including a body-only identifier.
