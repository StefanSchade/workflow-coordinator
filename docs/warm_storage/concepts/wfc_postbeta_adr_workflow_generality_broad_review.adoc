=== Blocking Finding (proposed new)

==== F-H002-01 -- the AD-1 boundary overstates the absence of phase names in `src/`

*Invariant.* The AD-1 boundary statement must describe the real responsibilities
of kernel, compiler and resources, verified against the files, "without
overstating either way" (task, AD-1), and the ADR must not contradict itself.

*What the candidate says.* Two places assert exclusivity:

* line 110-111, in AD-1 `Architecture goal`: "... no phase name appears in it,
  the only such literals in `src/` being two artifact keys in the Front Door
  request parser."
* line 150-151, in the first row of the boundary table: "The only phase-name
  literals anywhere in `src/` are the two `robust@v1` artifact keys at
  `frontdoor/request.py:27`."

*What the files say.* `src/workflow_coordinator/commissioning.py` holds the
phase names as literal keys of the two shipped program records --
`"implement"`, `"broad_review"`, `"correct"`, `"focused_review"` at `:138`,
`:139`, `:140`, `:141` and `"implement"` again at `:153` -- and the entry phase
as the literal `"initial_phase": "implement"` at `:367`. `grep -n
'"implement"\|"broad_review"\|"focused_review"\|"correct"'
src/workflow_coordinator/commissioning.py` returns exactly those six lines; the
same search across the rest of `src/` returns only `frontdoor/request.py:27`.
So the second claim is false as written, and the first is false under the scope
it itself names (`in src/`).

*Why it is blocking rather than cosmetic.* The candidate's own compiler row
states the opposite four lines later -- "The entry phase is the literal
`"initial_phase": "implement"` (`:367`)" -- and cites the program records as
Python literals at `:130-155`. A reader who takes the exclusivity sentence at
face value concludes that nothing in the product spells a phase name outside
one artifact-key table, which is precisely the overstatement AD-1 is required
not to make, and it understates the compiler coupling that AD-1's third row and
AD-6 both rest on. The acceptance criterion names this statement specifically
("the AD-1 boundary statement is verified against the actual kernel, compiler
and resources"), so I record it as blocking without weighing how likely a
reader is to be misled.

*Feasible correction (one sentence each, no new material).* Qualify both
sentences to the distinction the ADR already draws elsewhere, for example: "no
phase name appears in the kernel modules; outside the compiler's own program
records and its entry-phase literal (`commissioning.py:138-141`, `:153`,
`:367`), the only phase-name literals in `src/` are the two `robust@v1`
artifact keys at `frontdoor/request.py:27`." No decision, reason, rejected
alternative or consequence changes.
