== Actors, triggers and milestone separation

* When implementation changes documented behavior, the implementer updates
  affected canonical documents in the same WorkItem and within its scope.
  Operating/usage, preparation, evidence and recovery changes specifically
  trigger checking affected Operator Manual sections. No documentation impact
  requires no artificial edit or form.
* If a necessary document or controlling record is outside scope, the actor
  names that exact source, required correction and reason in the result or
  handoff. The responsible maintainer arranges the scoped follow-up. An event
  occurring after the actor's Hop uses the same handoff; no agent must invent
  a future commit/outcome or edit an unauthorized record.
* At actual implementation, the implementer records changes, known commit,
  checks and remaining work in the controlling BUG/FTR, identifying outstanding
  independent acceptance. Local checks are not acceptance.
* After configured independent review and required Coordinator checks establish
  an outcome, the responsible maintainer records acceptance or the actual
  rejected/stopped outcome with evidence. Agent-reported success is insufficient.
* Product closure is recorded by the responsible maintainer only after remaining
  product obligations, including qualification, integration or promotion where
  applicable, are met. Implementation acceptance does not automatically close
  the issue. No additional approval role is introduced.
* The maintainer updates `_open.adoc` for material priority, readiness or
  dependency changes and keeps summaries consistent with controlling records.
  It remains the sole current priority/work overview, without a second event
  ledger or copied issue lifecycle.

These are upkeep responsibilities within existing authority, not new admission,
approval or review barriers. Configured Coordinator/review requirements retain
control. The recent backlog consolidation's qualified implementation,
acceptance and closure distinctions remain intact; none of its 48 technical
records is changed by this task.
