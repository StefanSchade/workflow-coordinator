= Standalone authority index

This is the single index of authority classes for the standalone Workflow
Coordinator repository. It classifies surfaces by
link:ai_info/doc_conventions.adoc[`Maturity`/`Authority`/`Owns`] where that
model applies, and points to the few surfaces it does not cover. It does not
duplicate any linked document's content.

*Runtime-authority fact, stated once:* nothing in this index, and no
`Maturity::`/`Authority::` pair alone, authorizes a Run, a provider
invocation, a Runtime promotion, or a repository mutation. Execution
requires an explicitly committed Commission/WorkItem/Profile/Policy under
`governance/`, in addition to whatever a document below describes or
classifies. No document below needs to repeat this.

== Surfaces outside the metadata model

[cols="2,3",options="header"]
|===
|Surface |Standing

|`governance/`
|Accepted self-development RepositoryPolicy, workflow profile,
prompt-component manifest, and committed WorkItem/task surfaces. Current
authority only within each surface's own declared ceilings; policy and
configuration, not documentation.

|`backlog/README.adoc`, `backlog/_open.adoc`, and backlog records (`+FTR-*+`/`+BUG-*+`)
|Own schema (`Status::`, `Disposition::`, `Evidence::`) -- a different
artifact type; §2 of the conventions does not apply. `_open.adoc` is the
sole active-work manifest.

|`warm_storage/concepts/` (other than the P3.5 design above)
|Active planning, design, and review evidence while its questions remain
under live discussion; not individually classified here. See the
consolidation plan for the tracked index of this evidence.

|`cold_storage/`
|Non-authorizing historical and traceability records, including the link:cold_storage/project_history/README.adoc[narrative history] and link:cold_storage/sources/pre-0.1.0b1/README.adoc[pre-beta source archive].

|`pyproject.toml`, `src/`, `src/workflow_coordinator/resources/`, `tests/`
|Define package and executable behavior; documentation cannot claim
behavior contradicted by these surfaces.

|`.claude/`, `.agents/`, `.codex/`
|May hold legitimate tool metadata; unrelated to documentation consolidation.
|===

== Planning and review evidence

Completed material, reviews, and historical stop records live under
`cold_storage/` as labelled provenance only; see the surfaces table above.
The maintainer has adopted the three model documents in the index above as
a deliberate, bounded extension of this architecture, to keep functional,
semantic, and technical concerns separately legible during Front Door
development; the 2026-10-15 documentation-architecture consolidation
(`cold_storage/concepts/history/workflow_coordinator_documentation_information_architecture_consolidation_2026-10-15.adoc`
§2, §7) governs that decision and is not reopened or amended by this index.
None of the three model documents is current authority or amends
`architecture.md`, the active-work manifest, or any accepted FTR.
