= Standalone authority index

Start with the link:../README.md[Repository README], or use the sources below.
This index provides navigation and identifies current contract owners; it does
not maintain a second copy of document metadata or feature status.
For a task-specific starting set, use the link:ai_info/_ai_info.adoc[task router].
link:ai_info/doc_conventions.adoc[Writing and upkeep conventions] explain how
to keep those sources current.

Execution authority comes from admitted Commission/WorkItem/Profile/Policy
inputs within their configured ceilings. Documentation, its metadata and
historical acceptance do not authorize Runs, provider invocations, Runtime
promotion or repository mutation.

For local document navigation, run `make doc-catalog`, then for example
`python3 scripts/wfc_doc_catalog.py query --title TEXT` or `query --id ID`
(with the same script). The derived catalog can become stale; regenerate it
explicitly. It grants no authority and raw header declarations are unverified.
Identity searches cover filenames, titles and identity headers, not body mentions;
use full-text search for those. `make doc-catalog-check` reports drift and
informational link and Project Memory source-path misses.

== Other sources

* `governance/` holds governing policies, profiles and WorkItems, effective
  only within their admitted scope and ceilings.
* link:backlog/_open.adoc[The backlog overview] is the sole current priority
  and work overview. Controlling BUG/FTR records hold technical scope and
  milestone evidence; link:backlog/README.adoc[backlog upkeep] distinguishes
  implementation, independent acceptance and product closure.
* Current models and operating documents are homes for distilled understanding
  needed to understand, maintain, develop and operate the present system;
  their stated draft or normative standing still applies.
* link:warm_storage/README.adoc[`warm_storage/`] holds relevant investigations,
  unresolved alternatives, active planning and concepts in development,
  grouped by workstream, including reviews still serving that work. Read them
  in context, not as blanket current requirements.
* link:cold_storage/README.adoc[Cold storage] is inactive long-term memory
  outside normal active context: earlier understanding, original rationale,
  rejected approaches, completed investigations/reviews, parked plans and
  valid but currently irrelevant ideas, including
  link:cold_storage/project_history/README.adoc[narrative history] and the
  link:cold_storage/sources/pre-0.1.0b1/README.adoc[pre-beta source archive].
  Inactive does not mean invalid. Retrieve selectively and reconsider conclusions
  against current sources; retrieval does not confer current authority. The
  link:ai_info/doc_conventions.adoc#_knowledge_homes[knowledge-home guidance]
  explains placement and distillation.
* Tool metadata under `.claude/`, `.agents/` and `.codex/` is separate from
  documentation organization.
