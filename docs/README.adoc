= Standalone authority index

This is the single index of authority classes for the standalone Workflow
Coordinator repository. It classifies surfaces; it does not duplicate their
architecture, roadmap, or content.

== Current authority

* link:../README.md[The repository README] is the project entry point for
  purpose, installation, and development basics.
* This `README.adoc` is the authoritative classification and index.
* link:architecture.md[Architecture] records stable system responsibilities and
  invariants.
* link:run-preparation.adoc[Run preparation] is the generic deterministic
  Run-preparation operator contract used once any semantic commission is
  committed, including the commission / `launch.sh` / provider-boundary
  distinction. It applies to self-development and to consumer repositories
  such as Core or Latin.
* link:self-development.adoc[Self-development] is the Runtime-N /
  Development-N+1 topology and promotion contract; it specializes, and refers
  to, the generic Run-preparation contract above for ordinary preparation
  mechanics.
* link:run-recovery-and-salvage.adoc[Run recovery and maintainer salvage] is
  the generic post-Run/Hop operator contract for same-Run reconcile/resume,
  maintainer salvage plus a fresh successor Run, forensic preservation, and
  discard, once a Run or Hop does not cleanly complete.
* link:project_memory.adoc[Project Memory] is an orientation pointer into the
  canonical structured memory under link:../project_memory/[`../project_memory/`]
  (`concerns.json`, `concern_events.json`, `concern_event_xrefs.json`,
  `decisions.json`). It does not override architecture or grant Run authority.
* link:backlog/README.adoc[The backlog index] records roadmap disposition and
  intent. It does not authorize execution.
* link:ai_info/_ai_info.adoc[The task router] is the compact agent-oriented
  current-reading path; it links to authority and does not create another
  authority index.
* link:backlog/_open.adoc[The active-work manifest] is the sole current work
  view. `cold_storage/` is non-authorizing provenance, not normal orientation.
* `pyproject.toml`, `src/`, and the package-owned operating contract under
  `src/workflow_coordinator/resources/` define package and executable behavior.
  Documentation cannot claim behavior contradicted by those surfaces.
* `tests/` provides executable verification and guards; tests do not grant Run
  authority.

`governance/` contains the accepted self-development RepositoryPolicy, workflow
profile, prompt-component manifest and components, and committed WorkItem/task
surfaces. They are current authority only within their explicit declared
ceilings. Committed governance alone neither starts nor authorizes a Run; each
real Run additionally requires explicit maintainer authorization.

== Provenance

`provenance/` records the mechanical carve-out lineage through
link:provenance/carveout.yaml[`carveout.yaml`] and
link:provenance/incubator-commit-map.tsv[`incubator-commit-map.tsv`]. These are
traceability records, not roadmap or execution authority.

== Historical / non-authorizing

Everything under `imported/core-incubator/` is pre-split historical evidence,
not current standalone authority. Its directory-level
link:imported/core-incubator/NOTICE.adoc[`NOTICE.adoc`] governs that
classification; individual historical files need no additional banner.

== Planning / review evidence

Active backlog sources under `backlog/` preserve the current proposal or
defect owner. Completed material, reviews, and historical stop records are
available under `cold_storage/` only as labelled provenance; neither grants
Run authority. Execution always requires separately committed applicable
authority.
