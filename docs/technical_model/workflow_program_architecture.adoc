= WFC Technical Model -- Interpreter, Workflow Programs, Commission Bindings
:toc:
:toclevels: 2

Authority:: Explanatory. This model explains how the implemented pieces fit
together; it grants no authority and replaces no accepted contract. Package
source, package resources and tests define executable behavior.
Standing:: Sections up to and including link:#routing-layers[routing safety] describe
*current implemented mechanics*, with the owning module named for each claim; the routing section explicitly labels its P3.5 exceptions.
link:#target[target architecture] onward remains a *working draft* of target hypotheses, deferred
design options and archaeology questions.
Updated:: 2026-11-15 -- current mechanics re-verified against
`src/workflow_coordinator/`, `governance/workflow-programs/` and the unit
tests; the earlier target discussion is retained and relabelled.

== How to read this model

link:../architecture.md[Architecture] gives the one-page responsibility
overview. This model is the next level down: which module owns which decision,
in what order, and what each layer can and cannot prove. Meaning of the
vocabulary belongs to
link:../semantic_model/workflow_execution_semantics.adoc[the Semantic Model];
operating procedures belong to
link:../operator_manual/operator_manual.adoc[the Operator Manual] and are linked
to rather than restated here.
