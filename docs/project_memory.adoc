== Durable constraints

* Runtime and development clones, their Git state, and external Run state stay
  separate. Development work never uses Runtime N as payload.
* A maintainer owns policy, WorkItem/task scope, acceptance, push, and runtime
  promotion. WFC cannot widen its own authority.
* Backlog and Project Memory record intent and accepted state; neither grants
  Run authority.
* Provider-requested approval or sandbox modes are not a trusted
  Coordinator-owned OS/environment containment boundary. That boundary remains
  deferred work.
* `--executable` currently selects a Codex-CLI-compatible executable seam for
  the concrete adapter; it is not a generic provider selector.
* No autonomous push or runtime promotion is permitted.
