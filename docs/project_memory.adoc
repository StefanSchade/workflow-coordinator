== Accepted decisions

* Accepted Runtime WFC N operates on Development WFC N+1; Runtime N never
  mutates itself.
* Push and runtime promotion are maintainer-owned decisions.
* One WorkItem mutates one repository.
* Imported Core material is provenance and history, not standalone authority.
* Project Memory remains lightweight unless evidence shows that more machinery
  is needed.

== Active work

* Active bootstrap slice: B2 -- bounded self-development authority/readiness.
  It is not implemented and requires later independent acceptance before
  first-dogfood readiness may be claimed.

== Durable constraints

* Runtime and development clones, their Git state, and external Run state stay
  separate. Development work never uses Runtime N as payload.
* A maintainer owns policy, WorkItem/task scope, acceptance, push, and runtime
  promotion. WFC cannot widen its own authority.
* Backlog and Project Memory record intent and accepted state; neither grants
  Run authority.
* Provider-requested approval or sandbox modes are not a trusted
  Coordinator-owned OS/environment containment boundary. That boundary remains
  deferred work.
* No autonomous push or runtime promotion is permitted.
