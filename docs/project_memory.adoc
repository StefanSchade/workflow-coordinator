Memory date:: 2026-10-12

The canonical standalone Project Memory is structured, flat JSON under
link:../project_memory/[`../project_memory/`], modeled on the canonical-data
principle from `spreadsheet-handling/core`'s `project_memory`:

* link:../project_memory/canonical/concerns.json[`concerns.json`] -- long-lived
  steering concerns.
* link:../project_memory/canonical/concern_events.json[`concern_events.json`]
  -- coarse historical/evidence events.
* link:../project_memory/canonical/concern_event_xrefs.json[`concern_event_xrefs.json`]
  -- the event-to-concern relation.
* link:../project_memory/canonical/decisions.json[`decisions.json`] -- stable
  decision anchors.

See link:../project_memory/README.adoc[`project_memory/README.adoc`] for how
these tables are meant to be read and updated.

This file, `docs/project_memory.adoc`, is an orientation pointer only. It is
not a second canonical memory database and is not maintained as prose history
in parallel with the JSON above. It grants no Run authority and does not
override architecture, governance, or backlog.
