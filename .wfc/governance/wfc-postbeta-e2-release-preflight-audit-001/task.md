DO: (1) Create scripts/wfc_release_check.py: read-only, writes nothing, no network. Mode comes from `git symbolic-ref -q HEAD` (attached = branch mode, detached = tag mode). Branch mode exits 1 on: branch not main; dirty tree; local main out of sync with origin/main; HEAD not reachable from origin/main; tag != "v" + version (the tag name is an argument or derived as the chapter specifies); missing or `planned` release-notes section for the version; any repository-relative documentation link in README.md. Tag mode (detached HEAD) skips the branch-identity and sync checks and instead exits 1 unless the checked-out commit is reachable from origin/main, plus the same version, notes and README checks. Output: one clear line per failed check, exit 0 only if all pass. Make the version read from pyproject.toml (tomllib) and the notes check parse docs/release_notes/release_notes.adoc as the chapter's C4 specifies. (2) Create scripts/wfc_dist_audit.py: takes the wheel and sdist paths, checks every archive entry against the C2 allow-list exactly as the chapter writes it (wheel: workflow_coordinator package .py files plus exactly the four reviewed resource texts and *.dist-info; sdist: pyproject.toml, setup.cfg, PKG-INFO, README.md, LICENSE, src/**), fails on anything unlisted and names the forbidden-by-name set explicitly in its message; it never modifies an artifact; one rule, one implementation. (3) Extend tests/architecture/test_offline_distribution.py so that it calls the audit on the artifacts it already builds (import or run the script; one implementation, two callers). (4) Create tests/unit/test_release_tooling.py covering both tools' refusals: synthetic temporary Git repositories (with a local bare 'origin') demonstrating branch mode and tag mode pass and every refusal above; synthetic wheels/sdists (zipfile/tarfile) showing the audit accepts a conforming artifact and rejects an unlisted entry, a forbidden entry and a missing resource; no real network, no dependency on this checkout's own state. (6) README.md: repair exactly the four repository-relative .adoc links to absolute tag-pinned repository URLs of the form https://github.com/StefanSchade/workflow-coordinator/blob/v0.1.0b1/<path> (see chapter C5), leaving every other word unchanged.
